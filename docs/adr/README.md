## What is an ADR?

Architecture Decision Records (ADRs) are short text files capturing an important architectural decision made in a project. Each ADR describes:

- **Context**: What is the issue that we're seeing?
- **Decision**: What is the change that we're proposing?
- **Consequences**: What becomes easier or more difficult to do?

This approach was pioneered by [Michael Nygard](https://cognitect.com/blog/2011/11/15/documenting-architecture-decisions) and is documented in [Documenting Architecture Decisions](https://adr.github.io/).
